# Glossary

| Term | Meaning as used here |
|---|---|
| **Jhāna** (Pali; Sanskrit *dhyāna*) | A state of deep, wakeful, pleasant absorption reached by meditation. Eight are traditionally listed |
| **Light / intermediate / deep jhana** | Three depths distinguished by Sparby & Sacchet [S13]. This project targets intermediate: it begins with a distinct shift in which attention locks onto the object |
| **Sutta jhana / Visuddhimagga jhana** | Older names for roughly intermediate and deep, after the texts each camp relies on |
| **ACAM-J** | "Advanced concentrative absorption meditation, jhāna": the Sacchet group's research term |
| **Samatha / samādhi** | Calm / collectedness. The family of practices and the quality of mind that jhana belongs to |
| **Access concentration** (*upacāra samādhi*) | The settled state just before jhana: attention continuous, thoughts faint and in the background |
| **Jhana factors** | The five qualities said to be present in first jhana: vitakka, vicāra, pīti, sukha, ekaggatā |
| **Vitakka, vicāra** | Applied and sustained attention (placing attention and keeping it there). Some translate them as thinking and examining |
| **Pīti** | Rapture: energetic, often bodily pleasure such as tingling, waves, warmth, a rush. Dominant in first jhana |
| **Sukha** | Happiness or joy: the quieter, more emotional pleasure. Dominant in second jhana, contentment in third |
| **Ekaggatā** | One-pointedness, unification of mind |
| **Upekkhā** | Equanimity: even, neither pleasant nor unpleasant. The mark of fourth jhana |
| **Formless jhanas** | The fifth to eighth: infinite space, infinite consciousness, nothingness, neither-perception-nor-non-perception |
| **Five hindrances** | Sense desire, ill will, sloth and torpor, restlessness and worry, doubt. Jhana requires them to be quiet |
| **Nimitta** | "Sign". In deep-jhana lineages, a stable inner light that becomes the object of absorption. Burbea also uses it loosely for the primary felt object |
| **Kasiṇa** | An external visual object (a disc, a flame) used to develop a nimitta |
| **Mettā** | Loving-kindness; goodwill. The commonest seed in fast-teaching methods |
| **TWIM** | Tranquil Wisdom Insight Meditation: a mettā-based method with a relax step after every distraction |
| **6Rs** | TWIM's routine on noticing distraction: recognise, release, relax, re-smile, return, repeat |
| **Energy body** | Burbea's term for the felt sense of the whole body as a field of sensation |
| **Cessation** (*nirodha*) | A complete gap in experience reported by some advanced practitioners. Out of scope |
| **Afterglow** | Calm, clarity and contentment persisting for hours to days after a jhana sit |
| **Seed** (this project) | Whatever a person uses to spark the first pleasant feeling: a smile, warmth for someone, a memory, the hands |
| **Loop gain** (this project) | The ratio of amplification to loss for a small pleasant feeling. Above 1 it grows by itself |
| **Ignition / take-off** (this project) | The moment the loop becomes self-sustaining |
| **Grasping** (this project) | Wanting more, trying to hold or increase the feeling, excitement, checking whether it is working |
| **Ladder** (this project) | Eight observable rungs from "did not settle" to "it deepened", used instead of a yes/no on jhana |
| **Blocker** (this project) | The failing link in the loop for a given sit, as diagnosed by the coach |
| **Lempel-Ziv complexity (LZ)** | A measure of how compressible a signal is. Higher means more varied. Reported higher in jhana |
| **Aperiodic (1/f) slope** | How steeply EEG power falls with frequency. "Flatter" means relatively more high-frequency power |
| **Criticality** | A dynamical regime between order and chaos. Jhana is hypothesised to move the brain toward it [S6, S7] |
| **Zygomaticus** | The cheek muscle that pulls the mouth into a smile. Its electrical activity contaminates scalp EEG |
