# Bibliography

Every source used in `docs/understanding/`, with how it was checked in this project:

- **[F]** fetched and read this session (full page, full text, or the abstract via the Europe PMC API)
- **[S]** seen only as a search-result snippet or listing; content not read
- **[M]** background knowledge, not re-verified this session. Treat details as unverified.

No quotation in these docs is longer than a short phrase, and all are from [F] sources.

## How the literature was found

A Europe PMC query for `jhana OR jhāna OR "absorption meditation"` (125 hits, November 2026) gave
the research list and abstracts. Teaching and first-person sources were located by web search
and read directly. A larger sweep of forum threads was planned and not completed (see
`docs/log.md` #6), so the first-person evidence base is small: see the caveats in
`02-first-person-reports.md`.
